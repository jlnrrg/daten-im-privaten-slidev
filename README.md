# Welcome to [Slidev](https://github.com/slidevjs/slidev)!

To start the slide show:

- `pnpm install`
- `pnpm dev`
- visit <http://localhost:3030>

Edit the [slides.md](./slides.md) to see the changes.

Learn more about Slidev at the [documentation](https://sli.dev/).

## Addons

The presentation features a [funny timer](https://github.com/kaakaa/slidev-addon-rabbit).<br>
You can access this by adding `?time=10` to the url.
[Example](https://jlnrrg.github.io/daten-im-privaten-slidev?time=10)
